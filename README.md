# Noopie — site vitrine

Export statique du site Noopie (accueil, commande, paiement en démonstration, pages de l'application).

- `index.html` : page d'accueil
- `commander.html` : choix de la couleur et de la version chien / chat
- `paiement.html` : page de paiement (mode démonstration, Stripe non connecté)
- `presentation-home.css` : styles spécifiques de l'accueil

Netlify publie la racine du dépôt (voir `netlify.toml`), sans étape de build.
